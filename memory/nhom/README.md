# Nhịp nhóm — một file một nhóm

`skills/nhip-nhom` và `skills/thong-bao-lich` ghi vào đây, mỗi nhóm một file
`{groupId}.md`. Đọc trước khi gửi, để không nhắc trùng và không gửi quá một tin
một nhóm một ngày.

Nội dung file (git bỏ qua, chỉ giữ README này):

```markdown
# Nhóm {groupId}

- **ten:** (tên nhóm cho người đọc)
- **gui_lan_cuoi:** YYYY-MM-DD HH:MM
- **da_nhac:** (việc đã nhắc, mỗi dòng một cái, kèm ngày)
```

**Mốc giờ ghi đúng `YYYY-MM-DD HH:MM`.** Sai định dạng thì rào "một tin một
ngày" không tính được, và nhóm nhận tin hai lần.
