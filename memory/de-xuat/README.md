# Đề xuất cuối ngày — chờ chủ duyệt

Skill `hoc-lai` viết vào đây một lần mỗi ngày: bài học vận hành, chỗ sổ cần vá,
trang sổ còn thiếu. **Chỉ là đề xuất** — không có gì tự động vào `knowledge/wiki/`.

Chủ chốt số rồi thì người (hoặc coding agent) mới sửa trang sổ, rồi xóa dòng
tương ứng ở đây.

File ngày bị git ignore như `memory/` — trong này có chữ của khách.
